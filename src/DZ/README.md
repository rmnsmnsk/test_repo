# Программа сортировки чисел

# Описание
Программа считывает набор целых чисел из стандартного потока ввода, сортирует их и возвращает количество элементов, изменивших свою позицию при сортировке.

# Формат ввода
<количество_чисел>
<число1> <число2> ... <числоN>

# Компиляция
make        # Компиляция программы
make clean  # Очистка скомпилированных файлов
make test  # Программа запустится, введите тестовые данные с клавиатуры:
           # 1. Сначала введите количество чисел (например, 5) и нажмите Enter
           # 2. Затем введите числа через пробел (например, 3 1 4 2 5) и нажмите Enter
sort.s получен командой: gcc -S -O2 sort.c
